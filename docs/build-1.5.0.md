# Wordville 1.5.0 빌드 및 검사 결과

주민 전용 집 12채와 마을 생활 시설 13곳이 포함된 Android APK입니다.

이번 추가: 햄버거 가게, 아이스크림 가게, 펍, 미술관, 식물원. 기존 목장·헬스장·사우나·미용실·수영장·슈퍼·병원·카페를 포함해 시설별 활동 39개를 제공합니다. 활동은 게임 속 연습이며 실제 주문·예약·결제는 이루어지지 않습니다. 각 시설 방문 화면과 활동 기록은 기기 내부에 저장됩니다.

## 검사 결과

- 로직 자동 검사 17개 통과.
- 주민 집과 시설 DOM 상호작용 검사 통과.
- 실제 Chromium 모바일 브라우저 검사 통과: 집 12채, 시설 13곳, 활동·대화·단어 연결, 재실행 후 저장 복구, 320·360·390·768·1280px 너비.
- Android APK 생성, lint, APK 서명 검사 통과.
- Android 15 가상기기 검사 통과: 기존 학습 기능과 주민, 집 12채 방문, 시설 13곳 방문·활동, 단어 화면 연결, 기록 저장.
- APK 내 단어 5,620개 및 변경된 assets가 검사한 소스와 동일함을 바이트 비교로 확인.
- Galaxy 실물 기기에서의 설치·조작은 아직 확인하지 않았습니다.

## 현재 범위

집과 시설은 광장 아래 별도 선택 구역에서 열립니다. 주민이 실제로 시설에 걸어 들어가는 동작은 포함되지 않습니다. 미용실은 나의 스타일을 텍스트로 선택·저장하며 광장의 주민 외모는 바꾸지 않습니다.
