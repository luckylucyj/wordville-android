# Wordville 1.3.0 주민 주택

주민 12명에게 전용 주택, 4가지 성격 설정(성격·기질·특성·성향), 각 3개 실내 물건과 대사를 추가했습니다. 기존 광장은 유지되며 아래 주민 주택 구역에서 집을 선택합니다. 주민 대화창에서도 집 방문이 가능합니다. 방 안에서 물건 설명 확인, 대화, 이전·다음 집 이동, 해당 주민 단어 학습을 할 수 있습니다.

- 알렉스: 햇살 체육관집 / 트로피·운동 매트·훈련 일지
- 엘리엇: 바닷빛 서재집 / 원고 책상·벽면 책장·찻잔
- 하비: 초록 찻집 / 차 도구·건강 기록장·모형 비행기
- 샘: 리듬 다락집 / 기타·키보드·공연 포스터
- 세바스찬: 밤빛 작업집 / 컴퓨터·부품 서랍·야간 조명
- 셰인: 소박한 쉼터집 / 닭 그림·돌봄 기록판·안락의자
- 헤일리: 빛담은 사진집 / 카메라·사진 전시벽·전신 거울
- 레아: 숲속 창작집 / 이젤·나무 조각상·화분
- 마루: 별빛 연구집 / 망원경·실험대·로봇
- 페니: 포근한 독서집 / 독서 의자·학습 노트·분류 책장
- 애비게일: 보랏빛 탐험집 / 탐험 지도·광물 진열장·게임기
- 에밀리: 무지개 재봉집 / 재봉틀·색실 선반·패치워크 러그

## 확인 결과

- 기존 자동 검사 14개 통과.
- DOM 클릭 검사 통과: 집 12개, 프로필 48항목, 물건 버튼 36개, 대화 변경, 단어 연결 12개, 이전·다음 순환.
- JavaScript 문법 검사 통과.
- 모바일 브라우저 검사는 실행 환경의 socket 권한 제한으로 실행하지 못했습니다. tests/homes.cjs에 5가지 화면 크기와 전체 방문 동작 검사를 작성하고 GitHub Actions에 연결했습니다.
- Android 패키지 ID는 기존 검수본과 같으며 versionCode 5, versionName 1.3.0입니다. 새 APK는 아직 빌드하지 않았습니다.
- GitHub main 반영은 자동 승인 검토에서 차단되어 사용자 승인 대기입니다.
- 주민이 광장에서 집 안으로 걸어가는 동작, 실내 자유 이동 및 가구 배치 편집은 이번 구현에 포함되지 않습니다. 주택은 별도 선택 구역과 방문 화면으로 구성됩니다.
