# Wordville 1.6.0 장소·주민 상호작용 검사

## 구현

- 시설 13곳과 주민 집 12채를 연결한 생활 지도. 도로·출입구·주민 이동·입장·체류·이동 재개 상태를 구성했습니다.
- 주민별 선호 장소 4곳, 시간대별 목적지, 밤 귀가. 초대는 시간 변경보다 우선하며 해당 방문을 마친 뒤 평소 일정으로 돌아갑니다.
- 현재 위치 목록과 장소별 실제 체류 주민 목록. 이름을 눌러 대화하고 다음 이야기·같이 활동하기를 이용할 수 있습니다.
- 시설 활동 39개에 대한 현장 주민 반응, 장소별 2개 대화 주제와 주민 12명의 말투 반영. 대사는 준비된 문장입니다.
- 실내 주민 표시·움직임·말풍선, 최근 출발·도착·주민끼리의 대화 기록.
- 생활 지도에서 장소를 직접 눌러 방문. 빈 장소에 주민을 초대하면 출입구까지 길을 따라 도착한 뒤 대화할 수 있습니다.
- 기존 단어 5,620개, 학습 기록과 이미지 연결, 시설 활동 저장 유지.

## 사용

마을 생활 시설 → 장소 선택 → 현장 주민 이름 → 다음 이야기 / 같이 활동하기. 주민이 없으면 초대할 주민을 고르고 이곳으로 초대하기를 누르세요. 생활 지도와 현재 위치 목록에서 이동·도착을 확인할 수 있습니다. 밤에는 주민들이 집에서 시작합니다. 장소 활동 기록은 기기에 저장하며 주민 위치와 대화는 실행 중 시뮬레이션입니다.
