# Wordville 1.4.0 생활 시설

기존 주민 집 12채와 학습 기능을 유지하고, 별도 생활 시설 구역에 8곳을 추가했습니다.

| 시설 | 활동 |
| --- | --- |
| 목장 | 먹이 주기, 물 채우기, 우리 청소 |
| 헬스장 | 스트레칭, 근력 운동, 러닝 완료 기록 |
| 사우나 | 사우나·휴게실 휴식, 물 마시기 기록 |
| 미용실 | 단발·웨이브·짧은 머리 중 스타일 저장 |
| 수영장 | 자유형·배영 바퀴 수, 물 적응 연습 |
| 슈퍼 | 게임 장바구니에 우유·빵·사과 담기 |
| 병원 | 접수·예약 확인·대기 안내 역할 연습 |
| 카페 | 차·커피·샌드위치 주문 연습 |

시설마다 전용 픽셀 장면, 주민 소개, 영어 문장과 해석, 기존 단어장 연결을 제공합니다. 각 시설 기록은 별도 키(wordville.facilities.v1)로 기기에 저장됩니다. 기존 학습 기록과 코인에 영향을 주지 않습니다. 게임 속 연습이며 실제 결제·주문·진료 예약은 이루어지지 않습니다. 미용실 스타일은 텍스트 선택 기록으로, 광장의 주민 외모를 바꾸지는 않습니다. 시설은 광장 아래 별도 선택 구역이며 주민의 시설 출입 이동은 아직 없습니다.

## 검증

- 자동 검사 17개 통과(기존 14개 + 시설 데이터·상태 검사 3개).
- 기존 주택 상호작용 검사와 시설 DOM 상호작용 검사 통과.
- 시설 8곳, 동작 24개, 재실행 시 기록 복구, 시설별 초기화, 스타일 저장, 단어 연결, 이전·다음 이동, 손상된 기록·저장 실패 처리 확인.
- 시설 픽셀 장면을 이미지로 렌더링하여 확인.
- 실제 브라우저의 모바일 레이아웃 검사는 이 실행 환경의 브라우저 소켓 제한으로 미실행. 320/360/390/768/1280px 검사를 작성해 Actions에 연결.
- 새 APK 빌드 및 Galaxy 실기기 검사는 미완료. versionCode 6, versionName 1.4.0. GitHub 반영은 앞서 요청한 승인 대기 상태이므로 로컬 커밋만 작성.
